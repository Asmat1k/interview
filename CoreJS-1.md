# Вопросы к интервью CoreJS#1:

## Basic:

### Data types:
1. `String`
2. `Number`
3. `BigInt`
4. `Boolean`
5. `Undefined`
6. `Null`
7. `Symbol`
8. `Object`

### Number methods:
- `.toString(base)` - возвращает число как строку, также возвращает строковое представление числа num в системе счисления.
- `.toExponential(fractionDigits)` - возвращает строку с числом в экспоненциальной нотации с указанным количеством знаков после десятичной точки.
- `.toFixed(digits)` - возвращает строку с числом, записанным с заданным количеством знаков после десятичной точки.
- `.valueOf()` - возвращает примитивное значение числа.
Дополнительно:
- `isNaN(value)` - преобразует значение в число и проверяет является ли оно NaN.
- `isFinite(value)` - преобразует аргумент в число и возвращает true, если оно является обычным числом, т.е. не NaN/Infinity/-Infinity.
- `parseInt` и `parseFloat` - они «читают» число из строки. Если в процессе чтения возникает ошибка, они возвращают полученное до ошибки число. Функция parseInt возвращает целое число, а parseFloat возвращает число с плавающей точкой (удобно читать числа с единицей исчисления).

### String methods:
- `length` - длина строки
- `toLowerCase()`/`toUpperCase()` - смена регистра строки.
- `split('СИМВОЛ')` - возвращает **массив**, разбивает строку в массив по указанному символу.
- `repeat(count)` - возвращает **новую строку**, повторяет строку count раз.
- `includes(searchString)` - возвращает **true/false**, проверяет строку на наличие фразы/символа.
- `startsWith(value)` и `endsWith(value)` - проверяют, соответственно, начинается ли и заканчивается ли строка определённой строкой.
- `indexOf(searchValue)`/`lastIndexOf(searchValue)` - возвращает **позицию** символа в строке / последнюю позицию символа в строке.
- `slice(start, end)` - возвращает **новую строку**; первый параметр - начало, второй параметр - конец (по умолчанию до конца строки).
- `str.substring(start [, end])` - возвращает часть строки между start и end (не включая) end. Отрицательные значение интерпретируются, как 0.
**(Это — почти то же, что и slice, но можно задавать start больше end. Если start больше end, то метод substring сработает так, как если бы аргументы были поменяны местами)**
- `str.substr(start [, length])` - Возвращает часть строки от start длины length. В противоположность предыдущим методам, этот позволяет указать длину вместо конечной позиции.
- `replace(searchValue, newValue)` - ищет в строке указанное значение или регулярное выражение и возвращает **новую строку**, в которой выполнена замена на второй параметр.
- `replaceAll(searchValue, newValue)` - заменяет все найденные совпадения другой строкой или переданной функцией, и возвращает **новую строку**.
- `trim()`/`trimEnd()`/`trimStart()` - обрезает пробелы с обоих концов / в начале / в конце строки.

### String templates:
- Шаблонные литералы - это строковые литералы, допускающие использование выражений внутри.
- `${value} is in string ${str}` (выделяется при помощи косых кавычек - \``)

### Ternary operator:
- Используется, когда нужно определить переменную в зависимости от условия.
- Можно использовать несколько операторов подряд.
- Синтаксис: условие ? если верно : если не верно.
- `let result = условие ? значение1 : значение2;`

## Advanced Expressions

### Преобразование типов данных в Boolean, String, Number:
- Преобразование к типу Number выполняют следующие операторы:
  - Операторы сравнения (`>, <, <=, >=`).
  - Побитовые операторы (`|, &, ^, ~`).
  - Арифметические операторы (`-, +, *, /, %`). Обратите внимание, что оператор + с двумя операндами не вызывает неявное преобразование к числовому типу, если хотя бы один операнд является строкой.
  - Унарный оператор `+`.
  - Оператор нестрогого равенства `==` (а также `!=`). Обратите внимание, что оператор `==` не производит неявного преобразования в число, если оба операнда являются строками.

### Type conversions:
- `String(value)` / `value.toString()` - преобразование в строку.
- `Number(value)` / `+value` - преобразование в число:
  - undefined => NaN
  - null => 0
  - true / false => 1 / 0
  - string => Пробельные символы (пробелы, знаки табуляции \t, знаки новой строки \n и т. д.) по краям обрезаются. Если остаётся пустая строка, то получаем 0, иначе из непустой строки «считывается» число. При ошибке результат NaN.
- `Boolean(value)` / `!!value` - преобразование в логический тип:
  - Любая непустая строка => true

### Strict comparison **(===)**:
- Оператор строгого равенства `===` проверяет равенство без приведения типов. Если `a` и `b` имеют разные типы, то проверка `a === b` немедленно возвращает `false`.

### Object.is():
- Метод `Object.is()` не выполняет приведение типов.
- Определяет, являются ли два значения одинаковыми. Два значения являются одинаковыми в следующих случаях:
  - оба равны `undefined`
  - оба равны `null`
  - оба равны `true`, либо оба равны `false`
  - оба являются строками с одинаковой длиной и одинаковыми символами
  - оба являются одним и тем же объектом
  - оба являются числами и:
    - оба равны +0
    - оба равны -0
    - оба равны NaN
    - либо оба не равны нулю или NaN и оба имеют одинаковое значение
- Не схож с `===`:
  - `Object.is` считает значение -0 и +0 разными.

### var / let / const:
- **VAR**:
  - Объявления могут обладать глобальной или локальной (в пределах функции) областью видимости.
  - Переменные `var` могут быть объявлены повторно или обновлены.
  - Переменные `var` поднимаются в верхнюю часть своей области видимости и инициализируются со значением `undefined`.

- **LET**:
  - Имеет блочную область видимости.
  - Переменные `let` могут быть обновлены, но не объявлены повторно.
  - Ключевое слово `let` не инициализируется. Если попытаться использовать переменную `let` до ее объявления, будет ошибка `ReferenceError`.

- **CONST**:
  - Имеет блочную область видимости.
  - Переменные `const` не могут быть обновлены или объявлены повторно.
  - `const`-объект не может быть обновлен, но свойства таких объектов можно изменять.
  - Объявления через `const` перемещаются вверх, но не инициализируются.

### Temporal Dead Zone (TDZ):
- **TDZ** - состояние, когда переменные недоступны, находятся в области видимости, но не объявлены.
- Переменная, объявленная с помощью `let` или `const`, не может быть доступна до ее объявления в пределах области видимости. Это вызовет ошибку ссылки или инициализации.

### Hoisting:
- Механизм в JavaScript, при котором переменные и объявления функций поднимаются вверх своей области видимости перед выполнением кода.
- JavaScript сначала объявляет, а затем инициализирует переменные.
- Объявления функций «поднимаются» над объявлением переменных, но не над их назначениями.

### Что такое полифилы (polyfills)?
- Термин **«полифил»** означает, что скрипт «заполняет» пробелы и добавляет современные функции.
- Полифил - это фрагмент кода (обычно JavaScript), который позволяет использовать современную функциональность в более старых браузерах, которые не поддерживают ее по умолчанию.
- Новые возможности языка могут включать встроенные функции и синтаксические конструкции. Транспилер переписывает код, преобразовывая новые синтаксические конструкции в старые. Но что касается новых встроенных функций, их нужно как-то реализовать. JavaScript является динамичным языком, скрипты могут добавлять/изменять любые функции, чтобы они соответствовали современному стандарту.

## Functions
- `«Function Expression»` (функциональное выражение):
  - Объявление функции в контексте какого-либо выражения, например присваивания.
  - **Не всплывает**.
  - Имеет собственный `this`.

- `«Function Declaration»`:
  - Функция, объявленная в основном потоке кода.
  - **Всплывает**.
  - Имеет собственный `this`.

- `«Arrow Function»`:
  - Функция не создает собственный контекст выполнения, она использует внешний. То есть, нет собственного `this`.
  - Стрелочные функции не могут быть использованы как конструкторы. Они не могут быть вызваны с `new`.
  - Не имеют `arguments`.

## Objects Built-in methods:
- `Object.create()` - используется для создания новых объектов и их привязки к прототипу существующего объекта.
- `Object.keys()` - создает массив, содержащий ключи объекта.
- `Object.values()` - создает массив, содержащий значения объекта.
- `Object.entries()` - создает вложенный массив пар ключ-значение для объекта.
- `Object.assign()` - используется для копирования значений одного объекта в другой объект.
- `Object.freeze()` - предотвращает изменение свойств и значений объекта, а также добавление или удаление свойств объекта.
- `Object.seal()` - предотвращает добавление новых свойств к объекту, но допускает изменение существующих свойств.
- `Object.getPrototypeOf()` - используется для получения внутреннего скрытого свойства [[Prototype]] объекта, которое также доступ

но через свойство `__proto__`.

## Arrays Built-in methods
- **МУТИРУЮТ:**
  - `push(...items)` - добавляет элементы в конец.
  - `pop()` - извлекает элемент с конца.
  - `shift()` - извлекает элемент с начала.
  - `unshift(...items)` - добавляет элементы в начало.
  - `sort(func)` - сортирует массив «на месте» и возвращает его.
  - `splice(start, deleteCount, ...items)` - изменяет содержимое массива, удаляя существующие элементы и/или добавляя новые.
  - `reverse()` - меняет порядок следования элементов на противоположный и возвращает изменённый массив.

- **ВОЗВРАЩАЮТ НОВЫЙ:**
  - `slice(start, end)` - копирует заданную часть массива и возвращает её в виде нового массива. Этот метод не трогает оригинальный массив. (Не включает start и end)
  - `concat(...items)` - возвращает новый массив, копирует все элементы текущего массива и добавляет к нему items. Если какой-то из items является массивом, добавляются его элементы.
  - `map(func)` - создаёт новый массив из результатов вызова func для каждого элемента.
  - `filter(func)` - фильтрует элементы через функцию и возвращает все значения, для которых функция возвращает true.

- **ПОИСК:**
  - `indexOf(searchElement, fromIndex)` - ищет элемент, начиная с позиции fromIndex, и возвращает его индекс или -1, если элемент не найден.
  - `includes(searchElement, fromIndex)` - возвращает true, если в массиве имеется элемент searchElement, в противном случае false.
  - `find(callback)` - возвращает значение первого найденного в массиве элемента, которое удовлетворяет условию, переданному в callback функции. В противном случае возвращается undefined. Callback принимает (element, index, array).
  - `findIndex(callback)` - похож на `find`, но возвращает индекс элемента вместо его значения.
  - `reduce(callback, initialValue)` - вычисляет одно значение на основе всего массива, вызывая callback для каждого элемента и передавая промежуточный результат между вызовами.

- **ПЕРЕБОР:**
  - `forEach(callback)` - вызывает callback для каждого элемента. Ничего не возвращает.

- **ПРЕОБРАЗОВАНИЯ:**
  - `split/join` - преобразует строку в массив и обратно.

- **ПРОВЕРКА:**
  - `Array.isArray(arr)` - проверяет, является ли arr массивом.

## Browser

### Events:
- События мыши:
  - `click` - происходит, когда кликнули на элемент левой кнопкой мыши (на устройствах с сенсорными экранами - при касании).
  - `contextmenu` - происходит, когда кликнули на элемент правой кнопкой мыши.
  - `mouseover` / `mouseout` - когда мышь наводится на элемент / покидает элемент.
  - `mousedown` / `mouseup` - когда нажали / отпустили кнопку мыши на элементе.
  - `mousemove` - при движении мыши.

- События на элементах управления:
  - `submit` - пользователь отправил форму.
  - `focus` - пользователь фокусируется на элементе, например нажимает на input.

- Клавиатурные события:
  - `keydown` / `keyup` - когда пользователь нажимает / отпускает клавишу.

- События документа:
  - `DOMContentLoaded` - когда HTML загружен и обработан, DOM документа полностью построен и доступен.

- CSS-события:
  - `transitionend` - когда CSS-анимация завершена.

## Design patterns:
- `KISS` (Keep It Simple and Straightforward) - провозглашает, что простота кода превыше всего, так как простой код наиболее понятный.
- `YAGNI` (You Aren’t Gonna Need It) - принцип, согласно которому следует писать код только тогда, когда в нем есть необходимость, а не исходя из предположений о будущих потребностях.
