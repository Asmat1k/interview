# Работа с материалами

Здесь собраны материалы для подготовки к собеседованиям по frontend-разработке: объяснения, примеры и практические задания.

- [Веб-платформа](web/html.md) — HTML, CSS, браузер и сеть.
- [JavaScript](javascript/types.md) — язык, асинхронность и работа с данными.
- [TypeScript](typescript/fundamentals.md) — типы и дженерики.
- [React](react/jsx.md) — компоненты, рендеринг и состояние.
- [Проектирование](engineering/principles.md) — принципы, паттерны и инструменты.
- [Практика](practice/implementations.md) — учебные реализации встроенных методов.

:::tip[Быстрая навигация]

На странице используйте оглавление, чтобы перейти к нужному вопросу. На телефоне оно находится в меню «Содержание этой страницы» над материалом.

:::

## Как запускать примеры

:::note[Перед запуском]

Примеры независимы друг от друга. Выберите окружение перед запуском:

- **Браузерный JavaScript:** выполняйте код на HTTP(S)-странице после разбора HTML.
- **Запросы к API:** пути `/api/...` предполагают работающий сервер с соответствующими маршрутами.
- **TypeScript, JSX и TSX:** используйте настроенную сборку. Нужные пакеты указаны в импортах.
- **React:** установите `react` и `react-dom`. Для `createRoot()` добавьте в HTML контейнер `<div id="root"></div>`.
- **Модули:** сохраняйте фрагменты с разными именами файлов отдельно.


:::
