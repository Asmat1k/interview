# Работа с материалами

Материалы сгруппированы по темам: веб-платформа, JavaScript, TypeScript, React, проектирование и практика. Объяснения из нескольких подборок собраны на общих страницах; дополнительные примеры дополняют основной разбор.

## Основы

Примеры независимы друг от друга. Браузерные фрагменты выполняйте на HTTP(S)-странице после разбора HTML; примеры TypeScript требуют компиляции. Модули с разными именами файлов сохраняйте отдельно.

Примеры независимы. Браузерный JavaScript выполняйте на HTTP(S)-странице после разбора HTML. Пути `/api/...` предполагают соответствующий сервер. JSX/TSX и TypeScript требуют настроенной сборки; пакеты для React, Redux и роутинга указаны в импортах.

## Общие вопросы по веб-технологиям

Примеры независимы друг от друга. JSX требует настроенной сборки и установленных пакетов `react` и `react-dom`. Импорты указаны в каждом примере, где они нужны. В примерах с `createRoot()` в HTML должен быть контейнер `<div id="root"></div>`.
